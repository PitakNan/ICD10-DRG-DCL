## 2. DCL คืออะไร (จุดที่มักเข้าใจคลาดกัน)

- `DCL` = **Diagnosis Complexity Level** — ค่าที่ **รหัสโรคหนึ่งให้ เมื่ออยู่ใน DC หนึ่ง**
- ค่านี้มีผลตอนรหัสนั้นไปเป็น **โรคร่วม/โรคแทรก (SDx)**
- **ใส่ PDx เดี่ยว ๆ ไม่มี SDx → DCL มักเป็น 0**

ตรวจกับโปรแกรมจริงแล้ว: `J440` และ `J441` ใส่เป็น PDx เดี่ยว ๆ ได้ **DRG 04550 ทั้งคู่ (DCL 0)**
ซึ่งตรงกับภาพหน้าจอที่คุณหมอส่งมา ส่วนค่า **DCL 2 และ 1** ที่ต้องการคือค่าจาก **ตาราง DCL** ใน DC 0455

## 3. วิธีได้มาซึ่งข้อมูล

### 3.1 ตาราง DCL (จาก PDF)
เขียน parser อ่านตาราง 10 คอลัมน์แบบ column-major รองรับ alias (`= F010` = ใช้ค่าเดียวกับ F010)

**การตรวจสอบ**
- ลำดับการอ่าน: ทุกบล็อกรหัสต้องมี DC เรียงน้อย→มาก → **ผ่าน 0 error ทั้ง 8 เล่ม**
- นับ token ต่อหน้าเทียบข้อความดิบ: ตรงกันทุกหน้า
- รวมทั้งชุด **814,870 คู่** ต่างจากข้อความดิบ 5 ตัว = ตัวอย่าง `0009:1` ในหน้าคำอธิบาย (4) + DC ซ้ำในบล็อกเดียว (1)
- รหัสในตาราง DCL อยู่ใน `c63i10` ครบ **100%**, DC ทุกตัวอยู่ใน `c63drg` ครบ **100%**

### 3.2 PDx → DRG group (ยิงจากโปรแกรมจริง)
ตาราง PDC → DC **ไม่มีในไฟล์ DBF** (อยู่ในตรรกะของตัวโปรแกรม) จึงต้องยิงทดสอบ

- ขับ TDS6307 ด้วยเมาส์/คีย์บอร์ดจริง อ่านผลจากหน้า "รายละเอียดการหา DRG" ผ่าน **clipboard** (ข้อความตรง ไม่ใช้ OCR)
- เคสมาตรฐาน: Age 70, Sex 1, Disc type 1, Adm Wt 70, LOSD 3, ไม่มี SDx/หัตถการ
- **ทุกแถวที่บันทึกต้องมี PDx ที่โปรแกรมสะท้อนกลับตรงกับรหัสที่ส่งไป** ไม่เช่นนั้นจะ retry แล้วบันทึกเป็น FAILED — ไม่มีทางบันทึกค่าที่ไม่ยืนยัน
- ยิง 3 รหัสต่อ PDC เพื่อตรวจว่ารหัสใน PDC เดียวกันให้ DC เดียวกันจริง

### 3.3 ผลการยิง

| รอบ | บริบท | รหัส | ผลสำเร็จ |
|---|---|---|---|
| 1 | ชาย 70 ปี | 540 | 540 (0 fail) |
| 2 | หญิง 30 ปี / ทารก / 25A | 70 | 70 (0 fail) |

- **169 จาก 170 PDC** ที่ได้ผลในรอบแรก **ทุกตัวอย่างให้ DC ตรงกัน** → ยืนยันว่าโดยทั่วไป PDC เดียวกัน = DRG group เดียวกัน
- **ยกเว้น PDC `25A` (เอชไอวี)** ที่แตกเป็น 4 DC (2550/2551/2552/2553) จึงยิงครบทั้ง 28 รหัส

### แท็บ 2 — เทียบโรคร่วม (Comobid DCL)
ตารางไขว้ **แถว = DRG group · คอลัมน์ = ICD-10 ที่เลือก · ช่อง = DCL** สำหรับเอารหัสที่ความหมาย
ใกล้เคียงกันมาเทียบว่าในแต่ละกลุ่มตัวไหนให้ DCL สูงกว่า

- เพิ่มรหัสได้ทีละหลายตัว (`J440,J441,J449` แล้ว Enter) ตั้งชื่อคอลัมน์เองได้ด้วยปุ่ม ✎
- ปกติแสดงเฉพาะกลุ่มที่มีรหัสใดให้ DCL > 0 · ติ๊ก "แสดงทุกกลุ่ม" หรือกรองด้วยชื่อ/รหัสกลุ่มได้
- สีเข้มตามระดับ DCL · **กรอบน้ำเงิน = ค่าสูงสุดของแถวนั้น**
- ตารางสรุปท้ายหน้าบอกว่ารหัสไหน "เป็นตัวสูงสุด" ในกี่กลุ่ม
- URL เก็บสถานะไว้ ส่งลิงก์ให้กันดูตารางเดียวกันได้: `#cmp/J440,J441,I10/0455,0459`
- ช่องค้นหาของแท็บนี้ค้นจากตาราง DCL โดยตรง ไม่ใช่จากรายการ PDx — เพราะมี **666 รหัส
  ที่ใช้เป็นโรคร่วมได้แต่เป็น PDx ไม่ได้** ซึ่งช่องค้นหาของแท็บ 1 จะหาไม่เจอ

## 5. ข้อจำกัดที่ต้องรู้

1. **ยิงตรงจากโปรแกรม 565 รหัส** ที่เหลืออนุมานจาก PDC ของตัวเอง — คอลัมน์ `source` ในไฟล์ Export บอกว่าแถวไหนเป็นแบบไหน (`grouper` = ยิงตรง, `pdc` = อนุมาน)
2. **DC ที่ต้องมีหัตถการถึงจะเข้าถึงได้** (กลุ่มผ่าตัด, เคมีบำบัด, รังสีรักษา, ส่งต่อ) ไม่อยู่ในตารางนี้ เพราะเคสทดสอบไม่มีหัตถการ — มี DRG group ที่มี PDx 181 กลุ่ม จากทั้งหมด 605 DC
3. **MDC 15 (ทารกแรกเกิด) 306 รหัส ไม่มี DRG group ตายตัว** — พิสูจน์แล้วว่ากลุ่มตัดสินด้วย **น้ำหนักแรกรับ** ไม่ใช่รหัสโรค (`P050` ให้ DC 1554 / 1553 / 1552 ที่ 3 / 2 / 1 กก.) จึงเว้นค่า DC ไว้
4. ตาราง DCL แสดงเฉพาะค่าที่ **ไม่เป็น 0** — รหัสที่ไม่ปรากฏ = DCL 0 ในทุก DC
5. ค่า DCL ในหน้าเว็บเป็นค่าตาม **ตาราง** ไม่ใช่ DCL สุดท้ายของเคส ซึ่งโปรแกรมคำนวณจาก SDx ทั้งหมดรวมกัน (และมี CC Exclusion เข้ามาเกี่ยวข้อง)
6. **DCL (0-5) คนละสเกลกับ CCC** (หลักที่ 5 ของรหัส DRG ที่กำหนด RW) — **428 จาก 485 กลุ่ม
   มี DCL สูงสุดเกิน CCC สูงสุดที่กลุ่มตัวเองมี** เช่น `1458` มี CCC แค่ 0 กับ 1 ต่อให้ลงโรคร่วม
   DCL 5 ก็ตันที่ระดับ 1 → **DCL สูงไม่ได้แปลว่า RW เพิ่มเสมอ ต้องดูจำนวนระดับของกลุ่มด้วย**
7. คอลัมน์ **"รวม"** ในแท็บเทียบโรคร่วมเป็นแค่ผลบวกไว้เรียงลำดับดูคร่าว ๆ **ไม่ใช่การคำนวณ CCC จริง**
   (โรคร่วม DCL 1 สามตัว ≠ CCC 3) สูตรรวม DCL → CCC ยังไม่มีในชุดข้อมูลนี้ ต้องยิง TDS6307 ยืนยัน
